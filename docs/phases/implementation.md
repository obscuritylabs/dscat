# Implementation phase

This role applies only when selected by [proportional routing](../workflow.md#phase-routing). The agent MUST first read [AGENTS.md](../../AGENTS.md) and the [planning index](../index.md), inspect Git status, and preserve unrelated changes.

This agent MUST follow the [workflow handoff](../workflow.md#bounded-handoff), verify its assigned revision and scope, and read [required sdlc and approval gates](../governance.md#required-sdlc-and-approval-gates), [traceability and change control](../governance.md#traceability-and-change-control), [definition of done](../governance.md#definition-of-done), [autonomous delivery ownership](../governance.md#autonomous-delivery-ownership), [engineering constraints](../engineering.md#project-and-engineering-constraints) and [catalog/licensing policy](../engineering.md#catalog-behavior-and-licensing), the requirements, acceptance, architecture dispositions and agent-authorized plan sections for this increment, and applicable [RTM](../rtm.md) rows. It MUST load linked details relevant to its assignment rather than unrelated transcript history.

The agent MUST implement only the agent-authorized increment, preserve unrelated changes, update traceability and documentation, self-review, and run applicable checks; it MUST NOT label self-testing independent verification.

The return MUST include the exact implemented revision/digest, changed artifacts/symbols, tests and results, manual verification material, limitations and any required review handoff. The implementer MAY retain routine corrections; fresh independent verification MUST follow review applicability rather than run for every increment. Documentation changes MUST receive [focused documentation QA/QC](../documentation-qa.md). Unavailable applicable evidence MUST remain explicit; separate release work MUST NOT block this task unless included in its scope.
