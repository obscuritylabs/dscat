# Planning phase

The agent MUST first read [AGENTS.md](../../AGENTS.md) and the [planning index](../index.md), inspect Git status, and preserve unrelated changes.

This agent MUST follow the [workflow handoff](../workflow.md#bounded-handoff), verify its assigned revision and scope, and read [required sdlc and approval gates](../governance.md#required-sdlc-and-approval-gates), [traceability and change control](../governance.md#traceability-and-change-control), [local verification and distribution](../governance.md#local-verification-and-distribution), [definition of done](../governance.md#definition-of-done), [autonomous delivery ownership](../governance.md#autonomous-delivery-ownership), [engineering constraints](../engineering.md#project-and-engineering-constraints) and [catalog/licensing policy](../engineering.md#catalog-behavior-and-licensing), approved requirements and architecture, [planning gates](../planning-gates.md), and applicable [delivery proposals](../delivery-plan.md). It MUST load linked details relevant to its assignment rather than unrelated transcript history.

The agent MUST define small increments, ownership, dependencies, test inventory, exact local checks, manual walkthrough, security evidence and release conditions; distinguish release delegation from ordinary plan approval.

The return MUST include an exact implementation-plan revision for human approval, increment handoffs, verification arrangements, and explicit release authorization status. Documentation changes MUST receive [full documentation QA/QC](../documentation-qa.md). Unavailable evidence and later completion stages MUST remain explicitly pending.
