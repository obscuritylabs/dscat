This is a planned test inventory under [DEC-047](decisions.md#dec-047), supporting the [increment map](implementation-plan.md#complete-requirement-and-artifact-map). V MUST inspect the inventory against actual code and acceptance; new behavior MUST gain tests. A case that is inapplicable MUST name a reason and revisit trigger in the evidence, never silently disappear. No dedicated performance SLO exists; safe finite resource ceilings are mandatory security behavior.

Tests MUST assert result/diagnostic model, stable code/location/exit, examined versus unexamined scope, no false success, old-byte preservation and correction/retry without accumulating state. Successful schema parsing or coverage MUST NOT substitute for semantic/security assertions. Expected invalid-input outcomes MUST count as test success only when the specified safe behavior is observed. Every source/built/released artifact result MUST identify exact hashes and actual platform/tool versions.
